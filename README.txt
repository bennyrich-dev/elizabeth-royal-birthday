ELIZABETH — ROYAL BIRTHDAY SURPRISE

OPEN THE WEBSITE
1. Download and extract the ZIP file.
2. Do not separate index.html from the assets folder. Keep them together.
3. Double-click index.html. It should open in your browser.

ADD THE BACKGROUND SONG
1. Place your MP3 copy of “No Bad Grade” inside the assets folder.
2. Rename the file exactly: no-bad-grade.mp3
3. Refresh the website. The Play/Pause button will play it.

EDIT THE CODE
Open index.html in Visual Studio Code. The HTML, CSS, and JavaScript are now spaced
out with indentation and section breaks to make them easier to read.

FILES
- index.html: the website
- assets/elizabeth-photo.jpg: Elizabeth’s photo
